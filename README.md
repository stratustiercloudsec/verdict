# The Verdict

**Decision intelligence for film & television investment.**
_The Bloomberg Terminal for entertainment financing._

Built by [Stratustier Innovation Labs](https://stratustierlabs.com) · Atlanta, GA

---

## What It Is

The Verdict replaces the static "script score" model used across the industry (a single opaque number generated by black-box ML on historical financials) with an **evidence-grounded, multi-agent AI reasoning system**. Instead of a number, executives get an explainable, confidence-scored, and — critically — *interrogable* investment recommendation. Every answer is traceable back to specific evidence rather than generated from a language model's parametric memory.

Upload a screenplay. Instead of `Overall Score: 84`, get an **Executive Greenlight Dashboard**:

- Commercial success probability
- Estimated audience (demo, psychographic, platform affinity)
- Comparable titles
- Projected production budget & break-even estimate
- Streaming retention impact, franchise potential, international appeal
- Recommended distribution strategy & release window
- Risk assessment

## The Differentiator: The Executive Boardroom

A conversational AI interface where executives interrogate the analysis directly, and the dashboard updates live:

> "Why shouldn't we greenlight this movie?"
> "What if Zendaya starred?"
> "What if we released it on streaming instead?"
> "How would Amazon MGM perform compared to Netflix?"

This is decision intelligence, not a static report — scenario-sensitive, real-time, and fully explainable.

## Long-Term Vision: An AI Operating System for Studios

The Verdict is designed to grow from a single-point analysis tool into an end-to-end pipeline:

```
Idea → Treatment → Script → Coverage → Budget → Casting →
Audience Forecast → Streaming Forecast → Marketing Strategy →
Greenlight Decision → Production Risk → Distribution Recommendation →
Release Optimization → Performance Tracking → Feedback into future predictions
```

## AI Architecture

The core principle: **the LLM is a reasoning and orchestration layer, not merely a text generator.** Structured extraction, deterministic calculations, retrieval, statistical models, and human input all feed the reasoning process — the model never operates on ungrounded intuition.

| Layer | Purpose | Approach |
|---|---|---|
| Script Understanding | Parse and structure the screenplay | Document parsing + NLP + structured extraction |
| Story Intelligence | Analyze narrative and characters | Bedrock LLM reasoning with page-level source citations |
| Market Intelligence | Assess market fit and competitive saturation | RAG over structured, curated, versioned market datasets |
| Comparable Engine | Find and explain relevant comps | Vector + metadata retrieval + LLM reasoning |
| Production Intelligence | Estimate complexity and requirements | Rule-based extraction + NLP + production heuristics |
| Financial Intelligence | Model budget ranges and sensitivities | Deterministic formulas + statistical models |
| Scenario Engine | Recalculate conditional outcomes | Scenario orchestration + sensitivity analysis |
| Verdict Layer | Synthesize evidence into a recommendation | Bedrock LLM reasoning with confidence & explainability |
| Boardroom Agent | Answer natural-language executive questions | Multi-tool Bedrock agent grounded in a project + org knowledge graph |
| Human Review Layer | Capture professional judgment | Structured annotations, overrides, decision records |
| Decision Replay | Learn from outcomes | Historical predictions vs. actual performance, org-specific tuning |

Key design decisions:
- Every intelligence output is stored with its evidence citations and confidence score at write time — not computed on demand — so the Boardroom's answers are instant rather than a fresh multi-minute analysis per question.
- Scenario variables are modeled as a first-class, versioned object separate from the base project, so multiple scenarios can be saved, compared, and replayed without mutating the canonical analysis.
- The Decision Record schema is designed from V1 to eventually hold an actual-outcome field (empty until later phases), enabling Decision Replay without a schema migration.

## Tech Stack

- **AI/ML:** Amazon Bedrock (LLM reasoning & agents), RAG over versioned market/comp datasets, knowledge-graph-grounded retrieval
- **Compute:** AWS Lambda, Step Functions
- **Data:** DynamoDB, S3, API Gateway, Cognito
- **Frontend:** React / Vite
- **Precedent:** Architecture informed by [AirDate.TV](https://airdate.tv), a live, revenue-generating serverless AWS/Bedrock RAG platform built by the same team
